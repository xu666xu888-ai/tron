# Issue tracker: GitHub

Issues and specifications live in https://github.com/xu666xu888-ai/tron/issues.
Use `gh issue list --state all`, `gh issue view NUMBER --comments`, `gh issue create`,
`gh issue edit`, and `gh issue close` with `--repo xu666xu888-ai/tron`.

Read the current issue body and relevant comments before implementation. Keep the body as
the current acceptance snapshot and comments as history. Include Current Status,
Current Acceptance, Constraints / Authorized Side Effects, and Verification.

No triage label vocabulary is configured. Do not invent labels.

PRs as a request surface: no.

Publishing to the issue tracker means creating or updating a GitHub issue. Fetching a
ticket means reading that issue. An issue alone does not authorize cloud mutations,
commits, pushes, or deletion.
